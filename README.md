# Projeto_pos - Repositório de Testes para Aulas de Engenharia de Dados

Este repositório foi criado para práticas e testes relacionados às aulas de Engenharia de Dados em nível de pós-graduação.

## 📚 Estrutura do Repositório

```
Projeto_pos/
├── aulas/              # Exercícios e códigos das aulas
├── projetos/           # Projetos práticos
├── exemplos/           # Exemplos de código e datasets
├── testes/             # Testes unitários e de integração
└── docs/               # Documentação e materiais de apoio
```

## 🎯 Objetivos

- Praticar conceitos de Engenharia de Dados
- Desenvolver pipelines de dados
- Trabalhar com diferentes tecnologias de armazenamento e processamento
- Implementar ETL/ELT processes
- Explorar ferramentas de Big Data

## 🛠️ Tecnologias Utilizadas

- **Python**: Linguagem principal
- **Pandas/Polars**: Manipulação de dados
- **SQL**: Consultas e modelagem de dados
- **PySpark**: Processamento distribuído
- **MongoDB**: Banco de dados NoSQL
- **PostgreSQL**: Banco de dados relacional
- **AWS**: Serviços de nuvem

## 🚀 Como Começar

1. Clone o repositório:
```bash
git clone https://github.com/Danmecpy/Projeto_pos.git
cd Projeto_pos
```

2. Crie um ambiente virtual:
```bash
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```

## 📝 Estrutura de Aulas

Cada aula terá sua própria pasta dentro do diretório `aulas/` com:
- Código de exemplo
- Exercícios práticos
- Datasets de exemplo
- README com instruções específicas

## 🧪 Testes

Para executar os testes:
```bash
pytest testes/
```
