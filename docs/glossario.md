# Glossário de Engenharia de Dados

## A

**API (Application Programming Interface)**: Interface que permite a comunicação entre diferentes sistemas de software.

**Apache Spark**: Framework de processamento distribuído para big data.

**AWS (Amazon Web Services)**: Plataforma de serviços de computação em nuvem da Amazon.

## B

**Batch Processing**: Processamento de dados em lotes, geralmente executado em intervalos programados.

**Big Data**: Conjuntos de dados muito grandes ou complexos que exigem ferramentas especializadas para processamento.

## C

**Cloud Computing**: Fornecimento de recursos de computação através da internet.

**Clustering**: Agrupamento de dados similares.

## D

**Data Lake**: Repositório centralizado que armazena dados estruturados e não estruturados.

**Data Pipeline**: Série de processos que movem dados de uma origem para um destino.

**Data Warehouse**: Repositório central de dados integrados de uma ou mais fontes.

**Data Mart**: Subconjunto de um data warehouse focado em uma área específica.

**Dimensão**: Tabela em um modelo dimensional que contém atributos descritivos.

## E

**ELT (Extract, Load, Transform)**: Processo onde dados são extraídos, carregados e então transformados.

**ETL (Extract, Transform, Load)**: Processo de extração, transformação e carregamento de dados.

## F

**Fato**: Tabela em um modelo dimensional que contém métricas e chaves estrangeiras para dimensões.

## I

**OLAP (Online Analytical Processing)**: Sistema otimizado para consultas analíticas complexas.

**OLTP (Online Transaction Processing)**: Sistema otimizado para transações rápidas e frequentes.

## M

**MapReduce**: Modelo de programação para processamento distribuído de grandes datasets.

**Metadados**: Dados sobre dados; informações que descrevem outros dados.

## N

**NoSQL**: Banco de dados não-relacional que permite armazenamento flexível de dados.

**Normalização**: Processo de organização de dados em um banco de dados relacional.

## P

**Particionamento**: Divisão de grandes tabelas ou datasets em partes menores.

**PySpark**: Interface Python para Apache Spark.

## S

**Schema**: Estrutura que define a organização dos dados em um banco de dados.

**SQL (Structured Query Language)**: Linguagem para gerenciar e consultar bancos de dados relacionais.

**Streaming**: Processamento contínuo de dados em tempo real.
