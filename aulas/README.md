# Aulas - Exercícios e Códigos das Aulas

Esta pasta contém o material e exercícios de cada aula de Engenharia de Dados.

## Organização

Cada aula deve seguir a estrutura:

```
aula_XX/
├── README.md          # Descrição da aula e objetivos
├── exemplos/          # Exemplos de código
├── exercicios/        # Exercícios para praticar
└── dados/            # Datasets utilizados
```
