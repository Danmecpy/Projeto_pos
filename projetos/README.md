# Projetos Práticos

Esta pasta contém projetos práticos de Engenharia de Dados.

## Projetos Sugeridos

### 1. Pipeline ETL Simples
Extrair dados de uma API, transformar e carregar em banco de dados.

### 2. Data Warehouse
Criar um modelo dimensional e implementar um data warehouse.

### 3. Análise de Dados em Lote
Processar grandes volumes de dados usando PySpark.

### 4. Pipeline de Streaming
Implementar um pipeline de processamento de dados em tempo real.

### 5. Data Lake
Organizar e processar dados em um data lake na nuvem.

## Estrutura de um Projeto

Cada projeto deve conter:
- README.md com descrição e instruções
- Código fonte
- Scripts de configuração
- Documentação
- Testes
